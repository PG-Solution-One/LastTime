# Room schemas

Room экспортирует сюда историю схемы базы данных при сборке.

Каталог соответствует полному имени класса `LastTimeDatabase`, а имя JSON-файла
соответствует значению `version` в аннотации `@Database`:

- `1.json` — схема базы версии 1;
- после повышения версии до 2 появится `2.json`.

Числовые имена задаются Room и не должны изменяться вручную. Эти JSON-файлы
следует хранить в Git: они нужны для проверки и тестирования миграций.
